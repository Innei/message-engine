# Security Policy

## Supported versions

Until the first stable release, security fixes are applied to the latest published `0.x` version and the `main` branch.

## Reporting a vulnerability

Do not disclose suspected vulnerabilities in a public issue. Use GitHub's **Report a vulnerability** action on the repository Security page to submit a private report.

Include the affected version, reproduction conditions, potential impact, and any suggested mitigation. Reports will be acknowledged after triage; remediation timing depends on severity and the affected surface.

Provider credentials, prompts, and telemetry exports may contain sensitive information. Remove or redact them from reproduction artifacts unless they are strictly necessary for analysis.
